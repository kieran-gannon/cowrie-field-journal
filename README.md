# Cowrie Field Journal

A public experiment in AI-assisted threat intelligence from one high-interaction SSH honeypot.

- [Daily Brief](https://kieran-gannon.github.io/cowrie-field-journal/)
- [Methodology and reproducibility](METHODOLOGY.md)

Each brief exposes the aggregate data behind the findings. DeepSeek selects findings, and the generator renders them from validated references. See the methodology for the sensor setup, metric definitions, privacy boundaries, and model prompt.
